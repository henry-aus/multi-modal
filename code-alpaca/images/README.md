# Images Directory

## Training Progress Screenshot

Please save your training progress screenshot as `training-progress.png` in this directory.

The screenshot should show:
- Device detection (Using device: mps)
- Model loading status
- SFTTrainer creation success
- Training progress with metrics (loss, grad_norm, learning_rate, etc.)
- Progress bar showing training advancement

### Expected Image Content:
```
Using device: mps
Model loaded on device: mps:0
✅ SFTTrainer created successfully
Training on device: mps
Model device: mps:0
FP16 enabled: False
Starting training...
[Training progress with loss metrics and progress bar]
```

This image will be referenced in the main README.md file to showcase the successful training setup and progress.
